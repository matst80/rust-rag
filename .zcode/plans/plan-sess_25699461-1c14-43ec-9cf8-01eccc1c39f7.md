# Bottom resizable graph bar (code-symbol-graph.tsx only)

The `SymbolGraphSheet` currently renders a right-side shadcn Sheet. Change it to a bottom docked bar — no mount/API changes in `code-browser.tsx`, no new dependencies (the existing Sheet primitive already supports `side="bottom"` with slide animations; `react-resizable-panels` doesn't fit an overlay drawer).

**1. Dock bottom, default 50vh**
- `SheetContent side="bottom"` with inline `height: {heightVh}vh`; default **50vh**, clamped 25–85vh. Height lives in component state so it persists across open/close within the page session.

**2. Resizable top edge**
- Drag strip across the bar's top edge (grip pill, `cursor-row-resize`): pointer-capture drag up/down adjusts the height live.
- Double-click resets to 50vh; ArrowUp/ArrowDown nudge ±2vh (`role="separator"` + aria label for keyboard a11y).

**3. Inner layout reworked for a wide bar**
- Header (symbol kind/name/path/signature + caller/callee/node counts + depth stepper) stays on top, shrink-0.
- Below, a two-column split on md+: the reagraph canvas fills the left column (`flex-1` instead of the fixed `h-[320px]`, so the graph grows/shrinks with the bar); the "Called by"/"Calls"/unresolved lists scroll in a capped right column (`max-w-sm`, left border). On small screens: fixed-height canvas with the lists scrolling underneath.
- Outer `overflow-hidden` so the bar feels solid while dragging; only the lists column scrolls.

Verification: `npx tsc --noEmit` in `frontend/`, plus a quick read-through of the final component.
